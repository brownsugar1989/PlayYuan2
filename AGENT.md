# Project Instructions

## Project Overview
This is a browser-based Fruit Ninja game.
Built with HTML, CSS and JavaScript.

## Development Rules
- Preserve existing game functionality.
- Avoid unnecessary file restructuring.
- Do not rewrite working modules without reason.
- Keep changes limited to relevant files.
- Maintain mobile compatibility.

## Coding Rules
- Reuse existing functions where possible.
- Avoid duplicated code.
- Explain major architectural changes.
- Do not introduce dependencies without approval.

## Testing
- Test the modified functionality.
- Check browser console errors.
- Verify that existing game features still work.

## Debugging Rules:
- Do not repeatedly try random fixes.
- Identify the root cause before modifying code.
- After two unsuccessful approaches, stop.
- Summarize what has been tested.
- Explain the remaining possibilities.
- Ask for additional information if necessary.
